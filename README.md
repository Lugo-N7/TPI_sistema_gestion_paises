# Sistema de Gestión de Países en Python

Trabajo Integrador de Programación 1 desarrollado en Python.

## Descripción

Este proyecto consiste en un sistema de gestión de países desarrollado en consola utilizando Python y archivos CSV para el almacenamiento de datos.

El programa permite administrar información de distintos países mediante funcionalidades de carga, búsqueda, actualización, filtrado, ordenamiento y estadísticas.

---

## Funcionalidades

* Cargar países desde archivo CSV
* Guardar datos en archivo CSV
* Agregar nuevos países
* Buscar países
* Actualizar información
* Filtrar por continente
* Filtrar por población
* Filtrar por superficie
* Ordenar por nombre
* Ordenar por población
* Ordenar por superficie
* Mostrar estadísticas generales
